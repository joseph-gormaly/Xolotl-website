Technical & Legal Diligence

Frequently Answered Objections.

Under 18 U.S.C. § 2713, cloud providers must disclose customer data in their "possession, custody, or control." The Xolotl Canadian Core Mirror stores exclusively AES-256-GCM ciphertext and holds zero key shards. If served with a warrant, the cooperative can fully comply by turning over every byte—which is mathematically indistinguishable from random noise. Under established constitutional precedent, courts cannot compel the creation of backdoors that do not exist.
FROST signatures are strictly non-deterministic because they use fresh random nonces in every signing round (required by the RFC 9591 spec to prevent key leakage). Attempting to derive an AES key from a FROST signature produces a different key on every round, breaking deterministic file decryption. Xolotl solved this by pairing FROST authorization with an independent Threshold ElGamal Decryption engine with Chaum-Pedersen zero-knowledge proofs and per-session coordinate blinding.
Xolotl separates session authorization from ongoing file sync. An unlock ceremony is performed once at session start (taking ~1.5s across international nodes). While the session is active, files are encrypted and queued locally even if offline, and stream automatically to S3 once reconnected. Plaintext is never written unencrypted, and the ephemeral session key is zeroized upon signout or timeout.
The full codebase is implemented in Rust, TypeScript, and Docker across sovereign client and custodian enclaves (available for verification under institutional NDA). It passes live integration tests against Headscale WireGuard mesh networking, Supabase Postgres Row-Level Security, streaming AWS SigV4 multipart S3 uploads, and audited Ed25519 threshold crypto with all pre-audit security findings remediated. A formal RFP is prepared for tier-1 independent cryptographic review.
